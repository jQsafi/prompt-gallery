# Prompt Description
This prompt creates a dramatic color splash effect.

# The Prompt
```text
Convert the provided photo to black and white, but retain only the color of the {{retained_color_object}}.
Ensure all other elements are perfectly desaturated to grayscale, while the selected object remains vibrant and fully colored. The edges of the colored object should be clean and precise.
```

# Documentation
Provide a photo and specify the `retained_color_object` (e.g., "red rose", "blue car", "yellow umbrella").
