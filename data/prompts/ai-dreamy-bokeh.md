# Prompt Description
This prompt adds an artistic background blur with bokeh to a photo.

# The Prompt
```text
Apply a dreamy bokeh effect to the background of the provided photo while keeping the main subject sharp and in focus.
1. Identify the main subject and create a precise mask.
2. Apply a smooth, creamy blur to the background, simulating a wide aperture (e.g., f/1.4).
3. If applicable, render out-of-focus light sources as pleasing, soft circles (bokeh).
4. Ensure a natural transition between the subject and the blurred background.
```

# Documentation
Provide a photo with a clear main subject.
