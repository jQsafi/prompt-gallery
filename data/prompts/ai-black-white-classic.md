# Prompt Description
This prompt converts a color image to a timeless black and white.

# The Prompt
```text
Convert the color photograph to a classic black and white image.
1. Optimize contrast to create strong visual separation.
2. Ensure deep, rich blacks and clean, bright whites.
3. Preserve mid-tone detail and texture.
4. Apply a subtle amount of clarity for sharpness.
The goal is a sophisticated monochrome look, emphasizing shapes and light.
```

# Documentation
Provide a color photograph.
