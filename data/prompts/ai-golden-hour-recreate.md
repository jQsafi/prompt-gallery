# Prompt Description
This prompt recreates the beautiful lighting of golden hour in any photo.

# The Prompt
```text
Apply a golden hour effect to the provided photo.
1. Introduce a warm, golden color cast to the entire image.
2. Simulate soft, directional light from a low sun angle.
3. Create or enhance long, soft shadows.
4. Add a gentle glow to highlights.
The aim is a magical, ethereal atmosphere, as if photographed during sunset or sunrise.
```

# Documentation
Provide a photo taken in non-ideal lighting conditions that would benefit from golden hour light.
