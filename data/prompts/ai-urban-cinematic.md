# Prompt Description
This prompt gives an urban photo a dark, dramatic cinematic feel.

# The Prompt
```text
Apply a dramatic cinematic color grade to the provided urban landscape photo.
1. Desaturate greens and blues slightly.
2. Deepen shadows significantly, creating a moody atmosphere.
3. Add a subtle teal/orange split-toning effect.
4. Enhance atmospheric haze and fog if present.
5. Emphasize light sources as glowing elements.
```

# Documentation
Provide an urban landscape or cityscape image.
