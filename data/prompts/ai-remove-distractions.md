# Prompt Description
This prompt instructs an AI to remove unwanted elements from a photo.

# The Prompt
```text
Carefully identify and remove all distracting elements from the background and foreground of the provided image.
Specifically target: {{distractions_list}}
Ensure the removal is seamless and the generated content blends perfectly with the existing surroundings, maintaining perspective and lighting.
```

# Documentation
Provide a photo and a comma-separated list of items to remove (e.g., "power lines, litter, person in red shirt").
