# Prompt Description
This prompt enhances a landscape photo for a balanced HDR effect.

# The Prompt
```text
Apply an HDR effect to the landscape image.
1. Recover details in both the brightest highlights and darkest shadows.
2. Enhance local contrast to make textures pop.
3. Increase saturation subtly to make colors richer, especially greens and blues.
4. Maintain a natural, realistic appearance; avoid over-processed look.
```

# Documentation
Provide a landscape photograph, ideally with a wide dynamic range.
